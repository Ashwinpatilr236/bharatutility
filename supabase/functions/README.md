# Supabase Edge Functions Reference

The official source of truth and deployment pipeline for all Supabase Edge Functions (including `parksignal-alert` and `parksignal-bot`) is maintained in the central backend repository:
`arrjs-central-admin/supabase/functions/`

Do not deploy edge functions from this repository (`bharatutility`).
All production deployments must be executed through `arrjs-central-admin` using linked project `nyqjcfutsqgxpnisvggv`.
